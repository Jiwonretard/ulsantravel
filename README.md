# 울산 AI 여행 코스

사용자가 원하는 여행 분위기와 조건을 입력하면 실제 울산 관광지로 여행 일정을 추천하는 웹사이트입니다. 모든 추천 코스에는 울산의 블루베리 스무디 판매 카페 방문 일정이 포함됩니다.

## 주요 기능

- 여행 취향, 일정 길이, 동행자, 이동 방법을 반영한 울산 코스 추천
- 실제 울산 관광지와 카페 정보 제공
- 블루베리 스무디 판매 카페 중 한 곳을 무작위로 일정에 포함
- 카페 이름이 표시되는 확대·축소 가능한 지도
- 카페 메뉴, 가격, 주소와 확인 링크 제공
- 데스크톱과 모바일 화면 지원

## 실행 방법

프로젝트 폴더에서 아래 명령을 실행합니다.

```bash
python3 -m http.server 4173 --directory dist
```

브라우저에서 다음 주소를 엽니다.

```text
http://127.0.0.1:4173/
```

## 폴더 구성

```text
dist/
├── index.html                 웹사이트 화면
├── styles.css                디자인과 애니메이션
├── app.js                    코스 추천과 지도 기능
├── favicon.svg               사이트 아이콘
└── assets/
    └── association-logo.jpg  울산작은고래지킴이협회 로고
```

## 정보 확인 안내

카페 메뉴, 가격, 영업시간은 매장 사정에 따라 달라질 수 있습니다. `메뉴 확인` 또는 `지점별 판매 확인`으로 표시된 링크에서 방문 전에 최신 정보를 확인해주세요.
